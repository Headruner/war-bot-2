Static roster

Upload a JSON file of char_name + star_system_name pairs (at most {{ max_entries }} entries, {{ max_kb }} KB). They are ranked by stargate jumps on the Ranking page, on the Roster tab, and appear under the closest characters on the Alerts page. A roster entry has no tokens: nothing is ever read from ESI for it, so it shows no ship, no online state and no Set destination button. An upload merges into this pool by character name: names already here move to their new system and keep their tags and their Ranked setting.

File format (schema evedm-static-roster v1) 
{ "schema": "evedm-static-roster", "version": 1, "label": "Alt parking list",
  "characters": [
    { "char_name": "Tanya Vermaak", "star_system_name": "Perimeter", "tags": ["hauler"], "note": "Jita alt" },
    { "char_name": "Rork Sanhai", "star_system_name": "Osmon" } ] }

A bare array of those entries is accepted as the same version. A name that is not a solar system is kept as an unresolved entry with suggestions instead of being rejected; only the file as a whole is rejected (too large, not JSON, not the schema, or more than {{ max_entries }} entries). The file is not kept and its contents are never written to the log.
