# EVE Distance Meter: user guide

Step-by-step instructions for the main functions of EVE Distance Meter (evedm), written for the person using the site, not for the person running it. Every guide has numbered screenshots; the red numbers in the picture match the steps under it.

All screenshots come from the built-in demo mode (`evedm --demo serve`). The characters, systems, structures, wars and notifications in them are fictional, and the figures on your own site will differ.

| Guide | What you learn |
|---|---|
| [1. Getting started](01-getting-started.md) | Sign in with your main character, add your other characters, tag them, choose which ones are ranked |
| [2. Ranking](02-ranking.md) | Find the character closest to a system by stargate jumps, use pasted notification text, Thera and Turnur routes, the map, the phone layout |
| [3. Static roster](03-roster.md) | Rank characters that cannot sign in (alt lists, corp members) from a JSON file |
| [4. Notifications](04-notifications.md) | Read in-game structure notifications of all your characters, filter them, find the nearest character |
| [5. Structure alerts](05-alerts.md) | Follow destroyed structures and fights from zKillboard and send a character to the scene |
| [6. Structures](06-structures.md) | Browse shared structures, known structures without assets, and search any citadel |
| [7. Wars](07-wars.md) | New war declarations, statistics, and structures that can be attacked because of a war |

## Before you start

- Notifications and Structures can be limited by the site owner to members of an allowed alliance; if a menu item is missing, ask the owner.
- Use the menu at the top to move between pages: Ranking, Characters, Roster, Notifications, Alerts, Structures, Wars.
- The round **i** button at the top right opens a short help text for the page you are on.
- **Find route** buttons and system names on every page send that system to the Ranking page.
- The site works on a phone. The Ranking page then puts the map on top and its controls behind the gear button.
